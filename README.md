# DIGITAL SELLER — Painel Admin (Node + Neon)

Mesmo banco da loja get-access (`ep-bitter-credit`).

## Render
1. New → Web Service
2. Build: `npm install`
3. Start: `npm start`
4. (Opcional) `DATABASE_URL` = connection string do Neon DIGITAL SELLER
5. Deploy

Vídeos cadastrados aqui aparecem na loja get-access-node.

## API
- GET/POST `/api/videos`
- PUT/DELETE `/api/videos/:id`
- GET/POST `/api/settings/telegram`
- GET `/api/health`

## Local
```bash
npm install && npm start
```
